# 임계값 테스트 촬영 가이드

이미지 퀘스트는 "위치 200m 이내 + 기준 사진과 같은 구도"로 인증한다. 이 테스트는 CLIP 유사도가 **같은 구도로 다시 찍은 사진**과 **위치 조건은 통과하는 다른 사진**을 가를 수 있는지, 가른다면 임계값을 얼마로 둘지 정한다.

장소 10곳에서 사진 35장을 찍는다. 한 장소에 5분이면 충분하다.

## 준비

- 아이폰은 설정 > 카메라 > 포맷에서 **높은 호환성**(JPEG)을 고른다. HEIC도 읽을 수 있지만 실제 서비스는 JPEG을 받는다.
- 기본 1x 렌즈로 찍는다. 확대·광각·필터·인물 모드는 쓰지 않는다.
- 장소 10곳은 서로 다른 대상으로 고른다. 건물 입구, 벤치, 조형물, 가게 간판, 계단처럼 실제 퀘스트에 나올 만한 곳이 좋다.

## 찍을 사진

장소마다 번호(01~10)를 정하고, 아래 폴더에 **같은 번호를 파일 이름으로** 저장한다. 예: `ref/03.jpg`, `same/03.jpg`, `nearby/03.jpg`.

| 폴더 | 장수 | 무엇을 | 기대 결과 |
|---|---|---|---|
| `ref/` | 10 | 기준 사진. 등록자가 올린다고 생각하고 찍는다. | — |
| `same/` | 10 | 같은 장소에서 기준 사진과 **같은 구도**로 다시 찍은 사진. 수행자가 기준 사진을 보며 맞춰 찍는다고 생각한다. | 통과해야 함 |
| `angle/` | 5 | 장소 5곳만. 같은 대상을 **다른 구도**로 찍은 사진 (옆으로 45도 돌거나 뒤로 열 걸음 물러나서). | 팀에서 정할 부분 |
| `nearby/` | 10 | 기준 장소에서 **200m 안**의 다른 대상. 위치 인증은 통과하지만 다른 곳을 찍은 경우다. | 떨어져야 함 |

`same/`은 실제 수행처럼 조건을 일부러 다르게 한다. 10장 중에서 섞어서:

- 몇 걸음 떨어졌다가 돌아와 구도를 다시 맞춘다 (모든 장)
- 다른 사람이 찍는다
- 지나가는 사람이 함께 찍힌다
- 시간이 지나 밝기나 그림자가 다르다
- 살짝 기울어지거나 조금 더 가깝다

`nearby/`는 헷갈리기 쉬운 것을 고른다. 같은 건물의 다른 입구, 옆 벤치, 비슷한 간판처럼 생김새가 닮은 대상이 테스트에 가장 도움이 된다.

## 폴더 구조

레포 루트의 `data/threshold/`에 넣는다. `data/`는 커밋되지 않는다.

```
data/threshold/
  ref/01.jpg … 10.jpg
  same/01.jpg … 10.jpg
  angle/01.jpg … (5장, 번호는 ref와 같게)
  nearby/01.jpg … 10.jpg
```

분석 스크립트는 기준 사진끼리 번호가 다른 쌍(`ref/01` ↔ `same/02` 등)을 "다른 장소(교차)"로 자동으로 만들어 떨어져야 할 쌍에 더한다. 그래서 장소 10곳이 서로 달라야 한다.

한 장소에서 세트를 여러 개 찍었다면 `03a`, `03b`처럼 번호 뒤에 글자를 붙인다. 숫자가 같으면 같은 장소로 보고 교차 쌍에서 뺀다. 다른 구도나 근처 사진이 한 장소에 여러 장이면, 기준 사진을 `ref/03b.jpg`로 복사해 두고 `angle/03b.jpg`처럼 짝을 맞추면 된다.

## 분석

```bash
pip install -r threshold/requirements.txt
python threshold/analyze.py
```

결과는 `data/threshold/results/`에 저장된다.

- `pairs.csv`: 쌍별 유사도
- `summary.json`: 추천 임계값과 그룹별 통계
- `similarity-<모델>.png`: 발표에 쓸 분포 그래프

다른 모델과 비교하려면 `--model ViT-B-32:openai --model ViT-B-16:openai`처럼 여러 번 넘긴다.
